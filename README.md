This project is a high-performance, responsive single-page application built on **Angular 18** and styled with **Tailwind CSS**, designed to highlight enterprise-grade architecture, performance optimization, and professional experience.

---

## 🏛️ Project Architecture & Structure

This repository is split between the **Angular source code** and the **compiled static assets** served directly by GitHub Pages at the root.

```text
controlzeta.github.io/
 ├── netResume/              # Source code of the Angular 18 application
 │    ├── src/               # Application source files (components, models, assets)
 │    ├── angular.json       # Angular CLI configurations
 │    ├── package.json       # Dependencies, devDependencies & npm scripts
 │    └── tsconfig.json      # TypeScript compiler configurations
 ├── es/                     # Built static site for Spanish localization (Autogenerated)
 ├── en/                     # Built static site for English localization (Autogenerated)
 ├── en-US/                  # Built static site for English (US) localization (Autogenerated)
 ├── index.html              # Language redirector (reads navigator.language)
 └── .cursorrules            # Coding guidelines and development rules
```

> [!WARNING]
> **Important Deployment Rule:** Do not edit files in the `/es/`, `/en/`, or `/en-US/` directories directly. They are autogenerated outputs from the compilation process and will be overwritten during deployment. All code edits must be done inside the `netResume/` directory.

## 🛠️ Tech Stack & Features

* **Angular 18:** Leverages a modern architecture featuring standalone components, native Angular animations, and optimized lifecycle hooks.
* **Tailwind CSS (v3.4):** Implements a dark mode design system (Slate-950/Slate-900) with interactive transitions, custom card hover effects, and strict mobile-first responsive layouts.
* **i18n & Localization:** Fully localized using `@angular/localize`. The app is compiled into separate bundles per locale, maximizing runtime performance by removing execution-time translation layers.
* **PWA & Service Worker:** Integrated offline capabilities, asset caching, and progressive web application metadata.
* **Lucide Icons:** High-quality, lightweight SVG iconography.

## 💻 Getting Started (Local Development)

To run the project locally on your machine:

### Prerequisites
* [Node.js](https://nodejs.org/) (v18.x or v20.x recommended)
* Angular CLI v18.x installed globally:
  ```bash
  npm install -g @angular/cli
  ```

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/controlzeta/controlzeta.github.io.git
   ```
2. Navigate into the source code folder:
   ```bash
   cd controlzeta.github.io/netResume
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Development Server
Run the local dev server:
```bash
npm run start
```
Navigate to `http://127.0.0.1:4200/` in your browser. The application will automatically reload if you modify any of the source files.

## 🚀 Build and Deployment

The project is compiled and deployed directly to GitHub Pages. The build process uses Angular's localization compiler to generate translated folders.

To compile and publish the latest version, run the following command from the `netResume/` directory:

```bash
npm run deploy
```

### What this script does under the hood:
1. Compiles the Angular app for production with localization:
   ```bash
   ng build --configuration production --localize
   ```
2. Copies the build output from `netResume/dist/netResume/*` to the repository root.
3. Deploys the static assets using `angular-cli-ghpages`.

## ⚙️ Coding Guidelines & Rules (`.cursorrules`)

This project includes a [`.cursorrules`](file:///.cursorrules) file for AI development tools (like Cursor, Copilot, or Antigravity). These rules enforce:
* Standalone Angular components.
* Use of **Angular Signals** for reactive local state management.
* Prohibition of editing root deployment folders (`es/`, `en/`) directly.
* Performance best practices regarding DOM listeners (e.g. optimizing cursor-tracking events to prevent animation jank).
